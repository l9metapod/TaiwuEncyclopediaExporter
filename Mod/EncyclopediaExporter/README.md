# 百科导出工具 (EncyclopediaExporter)

将《太吾绘卷》内置百科（百晓册）重建为结构化的 **Markdown 文档**，在游戏内 Mod 管理器一键启用即可自动生成。

## 功能

- 读取游戏百科源数据（`StreamingAssets/Language_CN/EncyclopediaAssets/*.tsv`）
- 按游戏实际渲染逻辑重建为 188 个 Markdown 页面，包含：
  - 多级标题层级（章节 / 节 / 子节 / 条目）
  - 富文本转换（颜色、链接、列表）
  - 数据表格（品阶、属性、概率等自动转 Markdown 表格）
  - 百科内跳转链接（跨页面相对链接 + 锚点）
- **版本管理**：基于源文件 SHA256 哈希，游戏更新百科内容后自动检测并重建，未变更时秒级跳过

## 为什么导出？——让 AI 帮你做攻略

太吾绘卷机制庞杂，百科内容繁复。把这 188 页文档交给 AI，它就能读懂游戏，帮你：

- **设计 Build / 搭配出生效果**：「我走剑法流，出身特质怎么选？内力怎么调？」
- **解答机制**：「内息紊乱怎么解决？」「促织决斗的伤害怎么算？」
- **规划开局**：「少林派开局要注意什么？哪些功法值得优先学？」
- **对比分析**：「这几件武器哪个更适合我？」（附上相关表格）

## 怎么把文档交给 AI

导出的文档在游戏目录下的 `EncyclopediaExporter_Output/`（与 Mod 目录分开，避免上传创意工坊时把生成的文档一起打包）。下面两种方式任选其一，都不需要付费会员、不需要注册 API、不懂编程也能用。

### 方式一：本地 AI 工具（Agent）

这类工具装在电脑上，能直接读取你本地的文件夹，不用手动上传，问什么它会自己去找相关文档。适合经常用、想问很多问题的玩家。

**怎么用（通用步骤）：**
1. 装一个本地 AI 工具（市面上有不少免费的，挑一个顺手的即可）
2. 用它「打开文件夹」，选中 `EncyclopediaExporter_Output/` 这个目录
3. 新建对话，直接用大白话提问，比如「剑法流开局怎么选出身特质」

它会自动翻阅目录里的文档来回答你。不用担心文件多——你只管问，它自己决定读哪些。

> 小贴士：本地工具很多都提供免费额度，做这种"查资料+回答问题"的轻度任务通常够用，也不容易排队。

### 方式二：网页 AI（直接在浏览器里用）

如果你不想装额外软件，直接用浏览器打开一个 AI 网站也行。大部分网页 AI 都能免费使用，也能上传文件。

**怎么用（通用步骤）：**
1. 浏览器打开任意一个支持上传文件的 AI 网站（多数主流 AI 都支持，且都有免费额度）
2. 把 `EncyclopediaExporter_Output/` 里**和你问题相关的文件夹**拖进去上传（比如问武学就传 `修习/`，问战斗就传 `战斗/`）
3. 在对话框里提问

文档一共 188 个文件，一次全传可能太多，**按章节挑着传**效果更好。每个文件夹名就是对应主题（门派、修习、战斗、物品、产业……）。

### 提问示例

不管用哪种方式，都可以这样问：
- 「我玩少林派，前期功法学什么顺序比较好？」
- 「这两件武器属性对比一下，哪件更适合我？」（先传 `物品/` 文件夹）
- 「内息紊乱是什么意思，怎么恢复？」
- 「促织决斗的规则和伤害计算讲一下」

## ⚠️ 注意事项

- AI 偶尔会"编造"细节。涉及**复杂机制**（战斗结算、概率判定、特定事件触发条件）时，建议让 AI 给出依据，再对照原文档或游戏内验证
- 文档是游戏百科的静态快照，**不包含**你当前存档的具体数据（人物属性、背包物品等）——这类问题需要你额外描述
- 游戏更新后再次启用本 Mod 会自动重建，保持文档最新
- **重建采用白名单清理，安全保留你写的内容**：重建只删除本工具自己生成的页面和词条（已知路径），你在输出目录里写的任何笔记（`.md` 也保留）、`.obsidian`/`.claude`/`.git` 等配置都不会被删——可以把这个目录当工作区放心用，只有和生成文件同名的才会被覆盖

## 📋 内容覆盖说明

当前版本导出百科正文 + 部分悬浮词条详情。以下是具体情况，方便你了解哪些能问、哪些暂缺：

### ✅ 已包含

- **全部 12 章节**正文：启程、世界、人物、交互、修习、战斗、产业、物品、门派、游历、扩展、主页
- **数据表格**：出身特质、促织品级、各门派功法一览、建筑、材料、丹药等 100+ 张表格
- **列表与排版**：按游戏原版式还原（列表项、缩进、子标题层级）
- **词条跳转**：百科内交叉引用链接（如"内力属性"→对应详情页）
- **悬浮词条详情**（`词条/` 目录，共 1796 条）：功法、特性、出身特质、内力属性、招式五类，含：
  - **功法**（924 条）：品阶/类型/五行/门派、正练·逆练效果、破体破气、命中分段（力道/精妙/迅疾）、攻击范围、施展需要（蓄式/部位）、施展需求、属性加成、运功路径
  - **特性**（766 条）：类型、属性加成、效果说明
  - **出身特质**（48 条）、**内力属性**（36 条）、**招式**（22 条）：名称 + 描述/属性
- 百科正文里的功法/特性等链接，会指向对应的词条文件（Obsidian 悬浮即可预览）

### 🚧 暂未包含（后续版本完善）

- **更多词条类型**：武器、盔甲、书籍、药毒、建筑、宝物等约 1 万条悬浮卡片尚未导出（当前优先做战斗相关的功法/特性）
- **图片素材**：百科中的插图（建筑外观、人物立绘等）未导出

> 词条数据从游戏运行时配置读取（文字 + 数值），数值类字段（如功法威力）部分由服务端实时计算，无固定值，已在词条中标注。当前版本已覆盖战斗理解所需的核心内容。

## 👀 查看工具推荐

文档里保留了颜色标记（品阶、属性高低等用不同颜色区分），用的是 Markdown 支持的内联 HTML `<span style="color:...">`。**不同工具对这类标记的支持程度不一样**：

### ✅ 推荐使用

- **Obsidian**（[obsidian.md](https://obsidian.md)，免费）：完整支持内联 HTML 样式，颜色、表格、链接全部正常显示。直接用 Obsidian 打开 `EncyclopediaExporter_Output/` 文件夹即可，左侧自动生成目录树，体验最好
- **Typora**：所见即所得，颜色和表格显示正常
- **VS Code** + Markdown 预览插件：颜色和表格基本正常

### ⚠️ 可能显示不全

- **GitHub / Gitee 网页**：会**过滤掉 `style` 属性**，颜色不显示（但文字、表格、链接都正常，只是没颜色）
- **部分论坛/社区**：同样可能过滤内联样式，颜色丢失
- **普通记事本**：能看到全部文字内容，但会夹杂 `<span>` 标签代码

> **给 AI 用不受影响**：无论用什么工具查看，AI 都能完整读取文字内容（颜色对 AI 理解没有影响）。颜色标记主要是方便人类阅读时快速区分品阶高低。

> 提示：如果你觉得颜色标签碍眼，可以直接用 Obsidian 打开——它的渲染效果和游戏内百科最接近。你的 `EncyclopediaExporter_Output/` 里可能已经有一个 `.obsidian` 配置文件夹，说明之前用 Obsidian 打开过。

## 安装

1. 将 `Mod/EncyclopediaExporter/` 整个文件夹放入游戏目录的 `Mod/` 下
2. 启动游戏 → Mod 管理器 → 找到「百科导出工具」→ 启用
3. 启用时自动生成，完成后在游戏目录的 `EncyclopediaExporter_Output/` 查看输出

> 预编译版本已附带 `Plugins/EncyclopediaExporter.dll`，无需自行编译。

**手动重新导出**：在 Mod 管理器里打开本 Mod 的设置，把「强制重新导出」开关打开，点「应用」即可立即重建全部文档（不用重启游戏）。完成后开关会自动关闭。

哈希缓存放于 `C:\Users\<用户名>\AppData\LocalLow\Conchship\The Scroll of Taiwu\EncyclopediaExporter.cache.json`。

## 使用说明

- **首次启用**：自动检测并重建（约 10 秒）
- **再次启用**：若百科源文件未变，秒级跳过；若有变更，自动重建
- **强制重建**：删除上述缓存文件，下次启用即重建
- **查看结果**：游戏日志（`Logs/` 或 `Player.log`）中搜索 `[EncyclopediaExporter]` 查看执行信息

## GameVersion 字段

`Config.lua` 的 `GameVersion` 字段需与当前游戏版本匹配（格式 `0.0.x.y`），否则 Mod 可能被判为过期而无法启用。若遇到此问题，将字段改为游戏主菜单显示的完整版本号即可。

## 技术说明

所有解析规则均通过反编译游戏程序集（`Assembly-CSharp.dll` 的 `Game.Views.Encyclopedia` 命名空间）确认，与游戏实际渲染逻辑一致：

| 机制 | 来源 |
|---|---|
| 节点层级树 | `EncyclopediaDataManager.Init` + `EncyclopediaContentItem.ProcessIndex` |
| 布局（列表/缩进） | `Element.GetLayoutPadding` + `SingleTextElement` |
| 富文本转义 | `Extentions.ParseText` / `ColorReplace` |
| 表格渲染 | `TableElement.InitData` |
| 链接解析 | `LinkElement`（HyperLink→跳页 / Tips→保留文字）|

## 许可

本工具仅读取游戏的明文数据文件并转换格式，不修改任何游戏文件。
